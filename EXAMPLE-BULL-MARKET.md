# Bull-Market Scenario

The sample input in `data/sample-market-input.json` demonstrates:

- BTC above long-term and medium-term averages;
- positive EMA structure;
- constructive RSI and MACD;
- above-average volume;
- positive ETH/BTC rotation;
- non-extreme sentiment and volatility.

Run:

```bash
qmi-skill data/sample-market-input.json
```

The result is an illustrative rules output, not a live recommendation.
