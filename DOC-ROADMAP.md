# Roadmap

Potential future modules, not implemented in v1.0:

- reproducible historical backtest;
- live market-data adapters;
- stablecoin and exchange-risk scoring;
- on-chain flow observations;
- ETF-flow context;
- liquidation and order-book stress;
- news-event quarantine window;
- portfolio tax-lot awareness;
- human-approval execution adapter;
- signed audit logs.

Planned features must not be described as current capabilities.
