# Backtesting and Evidence Standard

This repository intentionally makes no historical-performance claim.

A future backtest is acceptable only when it publishes:

- data vendor and symbol mapping;
- exact start and end dates;
- indicator warm-up period;
- close-time and timezone;
- transaction fees;
- slippage model;
- funding costs if derivatives are used;
- rebalance timing;
- delisting and survivorship treatment;
- parameter version;
- code and machine-readable results.

Required metrics should include total return, maximum drawdown, volatility, Sharpe ratio, turnover, average exposure and benchmark comparison. A single favorable chart is not sufficient evidence.
