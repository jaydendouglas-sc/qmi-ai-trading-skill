# Contributing

Contributions should improve clarity, testing, safety or reproducibility.

1. Open an issue describing the proposed change.
2. Do not include private API keys, copyrighted datasets or copied strategy text.
3. Add tests for logic changes.
4. Update documentation and the changelog.
5. Do not publish performance claims without reproducible evidence as described in `docs/BACKTESTING.md`.

By contributing, you agree that your contribution may be distributed under the MIT License.
